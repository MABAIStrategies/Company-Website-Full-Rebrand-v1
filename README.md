# MAB AI Strategies — Company Website Rebrand (v1)

---

## Project Overview
This repository contains the codebase, asset pipeline, and deployment configurations for the comprehensive website redesign and full brand modernization of **MAB AI Strategies LLC** ([mabaistrategies.com](https://mabaistrategies.com)). 

The primary objective of this project is to transition our legacy digital presence into a cutting-edge, high-conversion enterprise platform that accurately showcases our operational mandate: **"Converting chaos into consistency, and consistency into currency."**

The v1 rebrand optimizes user experiences for enterprise clients, establishes an interactive automation showcase, streamlines scheduling for client consultations, and establishes a robust infrastructure matching our rigorous security frameworks.

---

## Brand Positioning & Core Capabilities
MAB AI Strategies engineers enterprise-grade AI automation ecosystems. The rebranded digital platform is structured around our major service vectors:
* **AI Agent Solutions:** Building bespoke, autonomous agents capable of handling tasks ranging from application vetting to multi-step API workflows.
* **Workflow Automation:** Deploying 24/7 background automations designed to eliminate recurring overhead costs and unlock net liquidity.
* **Full-Service AI:** Serving as an end-to-end partner for corporate clients via AI Readiness Audits, ongoing deployment scaling, and customized automation libraries.

---

## Technical Architecture & Migration Matrix
The upgraded tech stack replaces static components with a highly performant, server-rendered infrastructure designed to support complex animations, rapid load times, and dynamic user interfaces.

| Layer | Legacy Architecture | Rebranded Enterprise Infrastructure |
| :--- | :--- | :--- |
| **Frontend Framework** | Static HTML / Traditional CMS | **React** & **Next.js (App Router)** |
| **Styling & Animation** | Standard Utility CSS | **Tailwind CSS** & **Framer Motion** |
| **Backend Engines** | Monolithic Components | **Node.js** & **FastAPI (Python)** |
| **Database Infrastructure**| Local Data Layers | **PostgreSQL** |
| **Cloud Ecosystem** | Standard Shared Hosting | **AWS** / **GCP** / **Docker Containers** |
| **Security & Auditing** | Basic SSL Encryption | **SOC 2 Type II Alignment**, **GDPR Protocol**, **OAuth 2.0** |

## Rebrand Objectives & Deliverables
> **Enterprise Metric Emphasis:** The visual design must dynamically prioritize our proven market outcomes: $12M+ in B2B revenue impact, 16+ years of enterprise experience, and 15+ operational hours saved weekly per deployment.

* **Performance & SEO Optimization:** Utilize Next.js Static Site Generation (SSG) and Server-Side Rendering (SSR) to ensure maximum search engine visibility and sub-second load times.
* **Dynamic Automation Library:** Build a filterable component showcase where prospective clients can interactively reveal solutions to common administrative bottlenecks.
* **Streamlined Ingestion Funnel:** Implement a secure, frictionless interface for booking AI Readiness Audits and initial consultations directly with our staff.
